# Текущие ситуации вратаря

## Соперник атакует по центру
Оставайся за №2 на линии мяч — центр ворот. №2 предотвращает удар, ты закрываешь створ.

## Соперник атакует с фланга
Сместись по створу к стороне мяча. Не выходи к боковой линии; №2 закрывает прострел.

## Свободный мяч перед воротами
Используй `INTERCEPT` только когда наблюдение назначает тебя первичным. Иначе сохраняй створ.

## Мяч у тебя
Выбери самого дальнего открытого адресата: №4, высокий вингер, №2. Используй
`KICK` для далёкого и `THROW` для близкого. При блокировке всех линий — `CLEAR`.
