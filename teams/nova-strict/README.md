# Nova Vertical

Экспериментальный клон `nova-baseline`. Baseline за матч 0:0 не нанёс ни одного
удара, а суммарное продвижение всех его передач было отрицательным. Здесь
исправлены пять причин, найденных в разборе реплея.

| Находка | Ручка | Что изменено |
|---|---|---|
| SHOOT ни разу не попадал в маску: вратарь всегда числился блокирующим | `shared/perception.py` | `pass_line(..., ignore_ids)`; `_shot_geometry` исключает вратаря и возвращает его боковое смещение по каждому направлению; дальность удара `SHOT_RANGE = 30`. |
| Форвард не отрывался от мяча дальше 13 м | `shared/perception.py` | `dynamic_anchor` для №3/№4 при нашем владении: `ball_x + 26`, верхнее отсечение 46. |
| Владелец отдавал назад, DRIBBLE не выбирался | `strategy.md`, `players/*`, `shared/perception.py` | В наблюдении появились строки «ЛУЧШАЯ ПЕРЕДАЧА» и «ПЕРЕДАЧА НАЗАД ЗАПРЕЩЕНА»; `validate_semantics` отклоняет пас с отрицательным продвижением при открытой линии вперёд и пас ближе `MINIMUM_PASS_DISTANCE`. |
| Фолбэк отправлял владельца мяча в IDLE | `shared/commands.py`, `shared/runtime.py` | `repair_parameters()` достраивает недостающие параметры; `fallback_decision()` выбирает детерминированную команду вместо простоя. |
| Розыгрыш с центра уходил назад | `arena/arena.yaml`, `strategy.yaml`, `team.yaml`, `players/*` | Пресет `1-1-1-2-high` ставит №3/№4 на `x = -2.0`; в стратегии и ситуациях описан выход на точки `(+12, ∓14)`. |

## Маска из одной команды не идёт в модель

`shared/runtime.py` перед вызовом модели смотрит `allowed_commands()`. Если маска
содержит ровно одну команду, модель не выбирает тип — только координаты, а они
почти всегда совпадают с `dynamic_anchor()`. Замер по реплею: из 93 таких решений
91 попало в якорь ближе чем на метр, отклонений за матч было два (3.6 м и 36.1 м).
Поэтому команда собирается детерминированно через `forced_decision()`.

В реплее такие решения помечены `decisionSource: mask-forced` и стоят 0.75 мс
вместо 3.5 с. Реальный матч 12 с: 19 из 30 решений команды прошли без модели
(63%), такт упал с 7.7 до 4.8 с настенных.

Отключается для сравнения качества:

```bash
AFC_SKIP_SINGLETON_MASK=0 make offline-match HOME_TEAM=nova-vertical AWAY_TEAM=nova-baseline
```

Пресет `1-1-1-2-high` добавлен в общий `arena/arena.yaml`, потому что стартовые
координаты — константа арены, а не команды. `defaultFormation` в `team.yaml`
выбирает его автоматически при выборе команды в интерфейсе.

## Что проверять в следующем прогоне

- `BALL_KICKED kind=SHOT` ≥ 1 и SHOOT в маске > 0% решений;
- максимальный `x` игрока команды > 40, доля тиков с игроком при `x > 25` ≥ 20%;
- средняя продвижка передачи положительна, доля выбора максимального продвижения ≥ 7/8;
- `validationStatus != accepted` не приводит к IDLE у владельца мяча:
  в реплее вместо `error-idle` стоит `deterministic-fallback`;
- первая передача матча имеет продвижение > 0, мяч пересекает `x = 0` вперёд не позже t3.

Остальная структура и правила редактирования — как в
[`teams/nova-baseline/README.md`](../nova-baseline/README.md).
